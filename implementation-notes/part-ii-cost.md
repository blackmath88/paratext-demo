# Slice C — The cost

- **Persistent objects:** the same 16 operation groups and shared
  `operationStates`; the settled Read projection; `claim-presentation` as the
  tracked semantic object; the live frame switcher.
- **Transformations:** a reference marker establishes the tracked claim in the
  Read arrangement. Without user input, the field changes to `spec` through the
  shared layout writer. The claim travels into subordinate context at reduced
  opacity while its old marker stays put, making the loss of spatial certainty
  visible without deleting the operation.
- **New elements:** one latent scene-owned Cost annotation group: fixed tracking
  bracket, stable `§03` label, vendor-selection label, and short consequence
  notes. No new operation or duplicate representation.
- **Timeline range:** `.84–.92`, settle at the 70% choreography boundary. The
  `cost` entry moves from `plannedActs` into `acts`.
- **Reduced motion endpoint:** a stable Spec plate with the tracked claim held
  in subordinate context and the abandoned reference marker visible. The
  switcher remains usable after the endpoint.
- **Performance concern:** one 16-operation layout transition and a few static
  annotations. The switcher is gated during unsolicited movement so it cannot
  compete with the master timeline.
- **Visual claim:** adaptive framing has an epistemic and social cost. Stable
  identity is not the same as a stable mental model, shared pointing position,
  cross-session citation context, or control over who selects the view.
