# Slice C — fragmentation and conversation

1. **Persistent scene objects:** application shell and content, six latent
   window outlines, all 16 operation nodes, the continuous Latin artifact, and
   latent split-screen/problem markers.
2. **Object transformations:** six outlines peel away from the application
   boundary; operation nodes travel into separate tool frames and related nodes
   are pulled apart; those same nodes then leave their windows and settle into
   chronology beside the persistent artifact.
3. **New elements:** restrained window outlines/titles, cross-frame relation
   lines, conversation/artifact dividers, supersession warning and orphan-
   context marker.
4. **Timeline range:** Acts 00–05 occupy 0–.62; Fragmentation .62–.80;
   Conversation + Artifact .80–1.00.
5. **Reduced-motion endpoint:** readable multi-window fragmentation and stable
   conversation/artifact split-screen states.
6. **Likely performance concern:** 16 simultaneous SVG transforms plus six
   window path morphs. Geometry updates are bounded and no layout reads occur.
7. **Visual claim:** every tool is locally sensible, but related work is pulled
   into the gaps; conversation restores proximity while chronology flattens
   supersession and leaves provenance beside—not with—the artifact.
