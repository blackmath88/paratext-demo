# Slice A — beginning and admission

1. **Persistent scene objects:** body glyphs, leaf/edge/verso paths, gloss groups,
   handwritten rules and marks, and the existing print apparatus.
2. **Object transformations:** body contracts from field presentation into page
   measure; the latent leaf resolves; glosses accumulate beyond its edge; leaf
   geometry expands around them; the expanded object trims into print.
3. **New elements:** none. A separate Page timeline and an admitted-leaf geometry
   state are sufficient.
4. **Timeline range:** Presentation 0–.18; Page .18–.36; Outside voice .36–.70;
   Apparatus .70–1.00. The arriving act owns each seam, avoiding competing
   writes to the leaf path and preserving clean reduced-motion endpoints.
5. **Reduced-motion endpoint:** a meaningful held state at the end of every act:
   field text, bounded page, expanded annotated object, and printed apparatus.
6. **Likely performance concern:** deterministic `d` updates on three leaf paths
   during admission and trimming. No layout reads occur inside the tween.
7. **Visual claim:** reception first remains outside the authored object; the
   frame itself then yields to admit it, before print makes it reproducible.
